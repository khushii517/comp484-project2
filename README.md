# COMP 484 Project 2 - Giga Pet

An interactive Giga Pet game built with HTML, CSS, JavaScript, and jQuery.

## Live site

After enabling GitHub Pages, replace the URL below with your repository's actual Pages URL and submit that URL through Canvas:

**[Open the Giga Pet site](https://YOUR-GITHUB-USERNAME.github.io/comp484-project2/)**

## Features

- Treat increases Buddy's happiness and weight.
- Play increases happiness, decreases weight, and uses energy.
- Exercise decreases weight and energy.
- Rest restores energy and increases happiness.
- Weight, happiness, and energy are prevented from dropping below zero.
- Buddy displays a message after every action.

## Unique jQuery methods

The two methods selected for this project are not listed as already used or claimed in the provided sign-up sheet:

- [`on()`](https://api.jquery.com/on/) - handles the pet button events.
- [`html()`](https://api.jquery.com/html/) - displays Buddy's response message.

## Running locally

Open `index.html` in a browser. An internet connection is needed for the jQuery CDN script.

## GitHub Pages setup

1. Upload the project files to your GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main`, and select `/ (root)`.
4. Save, wait for GitHub Pages to publish, then update the live-site link above if your username or repository name differs.
